การเตรียมความพร้อมด้านเนื้อหา: ประสานงานทีมวิทยากรทั้ง 5 ท่าน ในการเตรียมเนื้อหาบรรยายและผลงาน Project Showcase ให้สอดคล้องกับหัวข้อกิจกรรม
3
การเตรียมกิจกรรมและของรางวัล: จัดเตรียมกิจกรรมเกมสำหรับให้ผู้เข้าร่วมงานได้ร่วมสนุกและแจกของรางวัล เพื่อกระตุ้นการมีส่วนร่วม

การเตรียมระบบประเมินผล: จัดทำแบบประเมินความพึงพอใจในรูปแบบ QR Code เพื่อความสะดวกในการเก็บข้อมูลหลังจบงาน

3. สรุปเนื้อหางานสัมมนา

3.1 ความแตกต่างและบทบาทของ UX และ UI

  • UX (User Experience): การออกแบบประสบการณ์ผู้ใช้งาน เน้นการวางโครงสร้างระบบ แก้ปัญหา และศึกษาพฤติกรรมผู้ใช้เพื่อให้ใช้งานได้ลื่นไหล เปรียบเสมือน "สถาปนิก" ที่ต้องวางโครงสร้างบ้าน
  • UI (User Interface): การออกแบบส่วนติดต่อผู้ใช้งาน เน้นความสวยงาม สบายตา การเลือกใช้สี ฟอนต์ และการจัดวาง Layout เปรียบเสมือน "มัณฑนากร" ที่ตกแต่งบ้านให้สวยงาม

3.2 หลักการออกแบบ UX และ UI ที่ดี

  • หลักการ UX ที่ดี: โครงสร้างข้อมูลชัดเจน ใช้งานง่าย (Usability) ลื่นไหล (Smooth User Flow) ตัวอย่างเช่น Shopee (ลดขั้นตอน), Netflix (แนะนำคอนเทนต์)
  • หลักการ UI ที่ดี: มีความเรียบง่าย (Simplicity) สอดคล้องกัน (Consistency) สื่อสารสถานะการทำงานชัดเจน (Feedback) เช่น Google Search, Apple Calculator
  • เครื่องมือสำหรับการออกแบบ (UX/UI Tools): แนะนำ Figma, Penpot และ Adobe XD รวมถึงสาธิตการสร้าง Prototype และการใช้ Figma AI (Make Design)

4. สรุปการนำเสนอโครงงาน (Project Showcase)

วิทยากรได้นำความรู้ด้าน UX/UI มาประยุกต์ใช้ในการพัฒนาโปรเจกต์จริง จำนวน 5 ผลงาน ได้แก่

โปรเจกต์ที่ 1: Khang Tang Maps (ระบบร้านค้าชุมชนข้างทางด้วยระบบแผนที่)

ผู้นำเสนอ: นายพงศกร บุษษะ

แพลตฟอร์มรวบรวมร้านอาหารและร้านค้าท้องถิ่นในจังหวัดเพชรบุรี ช่วยให้ค้นหาร้านเด็ดใกล้ตัวได้ง่าย พัฒนาด้วย HTML, CSS, JavaScript, PHP และแผนที่ Leaflet.js

โปรเจกต์ที่ 2: MobileShop (ระบบจำหน่ายมือถือออนไลน์)

ผู้นำเสนอ: นายภูริเดช ตะโกมา

เว็บแอปพลิเคชัน E-Commerce ที่เน้นแก้ปัญหาการเลือกซื้อ มีฟีเจอร์ Compare Specs แบบ Side-by-Side รองรับชำระเงินผ่าน QR Code PromptPay และ Dashboard จัดการข้อมูล

โปรเจกต์ที่ 3: ระบบคิดคำนวณรายได้และค่าแรงคนงานสวนมะพร้าว

ผู้นำเสนอ: นายกมลภพ อร่ามรักษ์

ระบบจัดการพื้นที่สวน คำนวณค่าแรงที่ซับซ้อน (เช่น สอยเป็นลูก ขนเป็นเที่ยว) บันทึกรายจ่าย และสรุปกำไรสุทธิ เพื่อแก้ปัญหาการจดบันทึกลงกระดาษที่มักสูญหาย

โปรเจกต์ที่ 4: Drive Easy (ระบบเช่ารถออนไลน์)

ผู้นำเสนอ: นายจักรกฤษณ์ นาคสุก

ระบบบริการเช่ารถที่ช่วยให้ลูกค้าตรวจสอบรถว่างตามช่วงเวลา คำนวณค่าเช่าอัตโนมัติ จองพร้อมชำระเงินทันที และผู้ดูแลระบบสามารถตรวจสอบรายการเช่าได้อย่างมีประสิทธิภาพ

โปรเจกต์ที่ 5: ระบบจัดการร้านอาหารสำหรับเจ้าของร้านรายเดี่ยว

ผู้นำเสนอ: นางสาวณฐกร เจะรัมย์

ระบบสั่งอาหารผ่านการสแกน QR Code (รองรับทานที่ร้านและสั่งกลับบ้าน) เพื่อแก้ปัญหาร้านอาหารที่พบปัญหาแซงคิว คิดเงินผิดพลาด ช่วยให้เจ้าของร้านทำงานคนเดียวได้สะดวกขึ้น

5. ปัญหา อุปสรรค และแนวทางแก้ไข

5.1 ปัญหาและอุปสรรคที่พบ

  • ด้านการรักษาเวลา: การนำเสนอและช่วง Q&A บางช่วงใช้เวลาเกินกำหนด ทำให้คิวงานช่วงหลังต้องกระชับขึ้น
  • ด้านเทคนิคและอุปกรณ์: พบความท้าทายในการสลับจอแสดงผลของวิทยากรแต่ละท่าน และการคุมความเรียบร้อยของไมโครโฟน
  • ด้านการมีส่วนร่วม: ผู้เข้าร่วมงานบางส่วนยังไม่กล้าแสดงความคิดเห็น ทำให้พิธีกรต้องใช้เวลาในการกระตุ้น

5.2 แนวทางการแก้ไขปัญหาหน้างาน

  • ทีมงานฝ่ายควบคุมเวลา: ประสานงานและส่งสัญญาณแจ้งเตือนวิทยากร เพื่อให้รวบรัดเนื้อหาเข้าสู่กำหนดการเดิม
  • ทีมงานฝ่ายเทคนิค (Control Room): เตรียมพร้อมสลับจอและทดสอบไมโครโฟนล่วงหน้า เพื่อลดระยะเวลา Dead Air
  • พิธีกร: เตรียมคำถามสำรองและใช้วาทศิลป์ในการกระตุ้นบรรยากาศ ในกรณีที่ไม่มีผู้ซักถาม

5.3 ข้อเสนอแนะสำหรับการจัดกิจกรรมครั้งต่อไป

  • ควรมีการเผื่อเวลาสำหรับช่วงการถาม-ตอบ (Q&A) ของแต่ละโปรเจกต์ให้มีความยืดหยุ่นมากขึ้น หรือกำหนดเวลาให้เคร่งครัดยิ่งขึ้น
  • ควรเพิ่มรอบการซักซ้อมคิวทางเทคนิค (Dry Run) โดยเฉพาะการสลับหน้าจอการนำเสนอให้มีความราบรื่นและไร้รอยต่อ
  • อาจเพิ่มรูปแบบกิจกรรมที่ใช้แพลตฟอร์มการมีส่วนร่วมออนไลน์ (เช่น Slido, Kahoot) เพื่อเปิดโอกาสให้ผู้เข้าร่วมพิมพ์คำถามเข้ามาได้
